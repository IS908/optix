# 2026-09-08 真实行情验收与修复

基线：`203c753`（PR #220）；验收期间纽约时间约 09:42–10:20，交易日、正常盘中。
所有诊断使用临时数据库、临时二进制和独立 API client ID；未修改正式账户数据库。

## 根因与处理

- **盘中空数据**：Gateway 握手成功，但原始回调报告 2105（美国历史数据场 `ushmds` 断开）。SPY/AAPL 历史请求超时。看板原先仅在连接失败时切换来源，连接成功后取数失败不会降级。现在为备用数据保留预算，批量取得 Yahoo 5 分钟 K 线，以对应 bar close 作为延迟价格；报价和 bars 按标的成对替换，保留来源、bar 时间戳及降级提示。历史请求退出时取消订阅。
- **期权采样偏离 ATM**：股价请求失败时，原先使用整个行权价列表中位数，SPY 采样中心约 711，实际价格约 767。现在复用不超过 30 秒的已取标的价格并保留来源；独立链查询可并行获取备用现价。没有可靠价格时不伪造 ATM/IV skew。Shock 仅采最近看涨与看跌合约，四个标的最多八个流；等待 IV、成交量和 OI，避免 OI 先到就结束。普通完整 OI 链仍保留原路径与并发限额，Yahoo 降级能力也有回归覆盖。
- **深度只返回约一半**：原始回调报告 309（同时最多三个深度订阅）。现在最多三个并发、四秒采集预算，对暂未释放的配额有限重试并遵守父请求取消。2152 表示部分交易所无权限，不能因此丢弃已授权交易所的深度；保留可用 rows 和权限提示。
- **报价串行耗尽覆盖预算**：Shock 中第一个慢报价会阻止其余股票请求；精选标的并行获取，各标的独立保留有效数据。
- **盘前量比与前收基准**：真实 Yahoo 盘前 bars 的成交量全为零，不能证明有效量比。现在 JSON 明确标记 `missing_metrics: ["vol_ratio"]`，CLI/网页显示“不可用”。同时排除 16:00 开始的盘后 bar，以最后一根正常交易时段 bar 计算前收；真实 NVDA 样本应使用 230.345，原先误用 229.82。
- **离线事件日历过期**：按 [BLS CPI 日程](https://www.bls.gov/schedule/news_release/cpi.htm) 和 [Fed FOMC 日程](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm) 补齐 2026 年剩余事件。官方日程核实日期：2026-09-08。
